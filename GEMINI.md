# New York LLC Publication

This extension connects Gemini CLI to a read-only MCP server from LLC Publishers, a document filing service for New York's LLC publication requirement. It has nine tools: the requirement and its deadline, county clerk details, LLC Publishers' price for a county, the step-by-step process, answers from LLC Publishers' FAQs and guides, how to start an order, drafting a publication notice, and checking a notice or a filing package.

Every tool description says when it fits and which tool fits instead. Answers are general information, not legal advice. LLC Publishers is a document filing service, not a law firm.

Guide: https://www.llcpublishers.com/learn/free-ny-llc-publication-tool-for-ai-assistants
